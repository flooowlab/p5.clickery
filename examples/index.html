p5.clickery examples

In learning order. Each one is a single folder you can read top to bottom.

  1. Quick start The smallest working game: one room, a hero, one sign. Start here. Rooms, hotspots, walking, look and interact, text keys.
  2. Core The game loop, timers and the state store, with save, load and export. createCore, scheduler, state, saveToSlot / loadFromSlot.
  3. Rooms Two scrolling rooms, an obstacle to walk around, depth scaling and three kinds of hotspot. Press D for the debug overlay. SceneManager, camera, Navigator, polygon / svg / colorMask hotspots, sorting by baseline.
  4. Adventure A puzzle with items and combining, an opening cutscene, a guard to talk to, music, sound, settings, and scaling to any window or phone. Inventory, cutscenes, dialogue in Markdown, Twine or Ink (add ?adapter=twine or ?adapter=ink), audio, settings, letterboxing.
  5. The Lighthouse A complete small game: three rooms, a puzzle, an Ink conversation, a skippable ending, save and load. How a real game is organised: data files, one script file per room, game logic with no drawing code (also the integration test).

Tool

  1. Room editor Load a room picture, draw hotspots and floors (or pick them with the magic wand), export the room JSON and preview it in the engine.
